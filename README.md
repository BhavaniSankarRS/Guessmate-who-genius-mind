
# Guess Mate - Character Guessing Game

Welcome to Guess Mate, an intelligent character guessing game that learns from your interactions!

## Features

- Think of any character (real or fictional) and answer questions
- Advanced AI algorithm predicts who you're thinking of
- Learning system that improves with each game
- Specially tuned for Indian celebrities, cricket players and Tamil cinema stars
- Professional UI with glassmorphic design and animations
- Contact section with developer information

## How to Play

1. Think of a person (celebrity, fictional character, family member, etc.)
2. Answer the questions with Yes, No, or Maybe
3. See if the game can guess who you're thinking about!
4. If the guess is wrong, you can teach the system by providing the correct character

## Technical Details

Built with:
- React
- TypeScript
- TailwindCSS
- Shadcn/UI components
